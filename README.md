# The Reading Room — v3

## 배포
기존 GitHub 저장소에서 `index.html`, `style.css`, `script.js`를 이 버전의 파일로 교체하고 Commit changes를 누르세요. GitHub Settings → Pages에서 `main` / `/(root)`를 사용합니다.

## 기능
- 연간 독서 캘린더와 한 책의 여러 독서 날짜 기록
- 페이지 수에 따라 책등 두께가 달라지는 빈티지 책장
- 책 정보: 저자, 장르, 출판사, 페이지 수, 0.5점 단위 별점, 독서평, 표지, 날짜
- 장르 추가 및 삭제 (해당 장르의 책은 삭제 시 '기타'로 이동)
- 책 표지별로 들어가 해당 책의 인상 깊은 문장을 모아보기/편집
- 읽고 싶은 책 목록, 교보문고 검색 바로가기, 경기도서관 홈페이지 바로가기
- 데이터는 브라우저 localStorage에 저장됩니다.

## 주의
GitHub Pages는 공개 웹사이트입니다. 이 버전의 데이터는 브라우저에 저장되므로 다른 기기와 자동 동기화되지 않습니다. 경기도서관은 홈페이지로 연결되며 검색어 자동 입력은 지원하지 않습니다.
