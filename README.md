# The Reading Room — Updated Edition

따뜻한 빈티지 서재 콘셉트의 개인 독서 기록 홈페이지입니다.

## 새로 추가된 기능
- 월별 캘린더: 책 한 권에 읽은 날짜를 여러 개 등록하면 해당 날짜 칸마다 책 표지 썸네일 표시
- 날짜별 보기: 날짜를 누르면 그날 읽은 책 표지 모아보기 (한 권을 여러 날짜에 반복 표시 가능)
- 연간 통계: 해당 연도에 읽은 책 수, 독서한 날짜 수, 독서한 달 수
- 일간 독서 일지: 날짜별로 책 표지와 책 제목을 모아보기
- 책별 문장 보관함: 책 한 권에 인상 깊은 문장을 여러 개 저장하고 출처도 각각 기록

## 기존 기능
- 책 추가 / 수정 / 삭제, 장르 분류, 별점, 독서평, 책별 복수 독서 날짜 기록
- 표지 이미지 URL 등록 (URL을 비워두면 임시 타이포그래피 표지)
- 브라우저 localStorage 자동 저장

## GitHub Pages 업데이트 방법
1. ZIP 압축을 풉니다.
2. 저장소 `jo3he6n/the-reading-room`의 최상위 화면으로 이동합니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 `index.html`, `style.css`, `script.js`, `README.md` 네 파일을 선택합니다.
5. 같은 이름의 기존 파일을 덮어쓰고 Commit changes를 누릅니다.
6. GitHub Pages가 다시 배포될 때까지 잠시 기다린 뒤 홈페이지를 새로고침합니다.

## 기존 기록 관련
이전 버전에서 브라우저에 저장했던 책 데이터는 같은 브라우저에서 새 버전을 열면 이어서 사용하도록 변환됩니다. 기존의 단일 읽은 날짜는 해당 책의 독서 날짜 목록 첫 항목으로 자동 이전됩니다. 새 버전에서는 책 수정 화면에서 읽은 날짜를 여러 개 추가할 수 있습니다. 이전 버전의 인상 깊은 문장(책당 한 문장)도 새 버전의 해당 책에 연결됩니다.
기록은 브라우저 localStorage에 저장되므로 브라우저 데이터 삭제나 기기 변경 시 사라질 수 있습니다. 별도 백업을 권장합니다.
