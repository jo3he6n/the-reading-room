# The Reading Room — v8 업데이트

## 적용 방법
1. 현재 GitHub 저장소의 `index.html`, `script.js`, `style.css`를 백업합니다.
2. 이 ZIP 안의 같은 이름 파일 3개를 저장소 루트에 업로드하고 기존 파일을 덮어씁니다.
3. 기존 `KcalliAutumnGothic.ttf` 폰트 파일은 삭제하지 말고 저장소 루트에 그대로 둡니다.
4. GitHub Pages를 새로고침합니다. 브라우저 캐시 갱신을 위해 CSS/JS 버전은 v8로 올려 두었습니다.

## 변경 내용
- 독서 날짜별로 '그날 마지막으로 읽은 페이지'만 입력하면 이전 기록과 비교해 읽은 쪽수와 구간을 자동 계산합니다.
- 예: 11월 12일 64쪽까지, 11월 13일 129쪽까지 입력하면 각각 1~64쪽(64쪽), 65~129쪽(65쪽)으로 기록됩니다.
- 캘린더 날짜 칸의 쪽수 배지를 제거해 책 표지가 더 깔끔하게 보입니다.
- 날짜 상세 영역과 책 기록 편집창에서 읽은 페이지 구간을 확인할 수 있습니다.
- 연간 통계에 요일별 읽은 쪽수 합계가 추가됩니다.
- 첫 화면의 사진 영역에서 서재에 등록된 책 중 현재 최애 책을 선택하면 해당 표지가 표시됩니다.

## 기존 데이터
- 책/인용문/위시리스트/장르 데이터 저장 키는 유지했습니다.
- 예전 날짜별 독서량(`dailyPages`)이 있으면 날짜순으로 누적해 마지막 페이지(`dailyEndPages`)로 변환합니다.
- 같은 브라우저와 같은 GitHub Pages 주소에서 파일만 교체하면 기존 localStorage 기록은 유지됩니다.
