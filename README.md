# The Reading Room v4

기존 GitHub 저장소의 `index.html`, `style.css`, `script.js`를 이 파일들로 교체하고 Commit changes를 누르세요. GitHub Pages는 `main` 브랜치의 `/(root)`에서 배포하면 됩니다.

## 이번 버전
- 도서관형 가로 책장, 책등 제목만 표시
- 페이지 수에 비례하는 책등 두께
- 장르별 책등 색상 직접 지정 및 장르 추가/삭제
- 전체 / 읽는 중 / 완독 / 중단 상태별 서재
- 읽는 중 진행률, 완독 별점 표시
- 평점/장르/읽은 날짜 정렬
- Wish List 장르 입력
- 기존 캘린더, 책별 인용문 보관 기능 유지

## 데이터
책/장르/색상/위시리스트는 브라우저 localStorage에 저장됩니다. 같은 브라우저에서는 기존 데이터가 유지되며, 다른 브라우저·기기와 자동 동기화되지는 않습니다.
